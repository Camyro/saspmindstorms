# AutoSave Mindstorms

## English

AutoSave Mindstorms automatically saves LEGO MINDSTORMS projects in the background, helping prevent progress loss caused by crashes or forgotten manual saves.

### Features

- Automatic project saving
- Runs in the background
- Lightweight and easy to use
- Helps prevent data loss

### Installation

1. Download the latest release.
2. Run the executable.

### Configuration

1. Open **Settings**.
2. Set the automatic save interval.
3. Customize the notification text (optional).
4. Enable or disable notifications.
5. Choose whether the program starts automatically with Windows.
6. Changes are saved automatically.

## Português

AutoSave Mindstorms salva automaticamente projetos do LEGO MINDSTORMS em segundo plano, ajudando a evitar a perda de progresso causada por travamentos ou pelo esquecimento de salvar manualmente.

### Recursos

- Salvamento automático de projetos
- Execução em segundo plano
- Leve e fácil de usar
- Ajuda a evitar perda de dados

### Instalação

1. Baixe a versão mais recente.
2. Execute o arquivo.

### Configuração

1. Abra **Configurações**.
2. Defina o intervalo entre os salvamentos automáticos.
3. Personalize o texto da notificação (opcional).
4. Ative ou desative as notificações.
5. Escolha se o programa deve iniciar automaticamente com o Windows.
6. As alterações são salvas automaticamente.
